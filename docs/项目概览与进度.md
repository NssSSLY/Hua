# 项目概览与进度

更新：2026-10-06。Hua 0.1.0-dev / 规范0.1 / Native ABI1 / HUAB写入6、读取1–6。

Hua已是可执行的语言原型：能检查与运行源码、导入本地模块、生成并运行HUAB，使用Native/WASM扩展和可选Python Bridge。已有14标准模块、115标准函数、38公开全局内建；Hua词法器能扫描自身，完整编译器尚未自举。

开始写程序见 [开发与运行指南](开发与运行指南.md)，查接口见 [标准库与内建接口](标准库与内建接口.md)。标准库下一阶段先审阅 [设计路线](标准库设计与实现路线.md)；候选接口不计为当前能力。

## 后续与交接

标准库按“本地基础→资源与取消→HTTP/进程→可选数据库→Agent包”小步验收；具体切片以设计路线为准。自举下一步为Hua AST/Parser，再做语义/降级、字节码/HUAB生成和连续自编译比较；沿用C++ VM/GC，HTTP、Agent或AOT不是前端自举的前提。

入口根、Task私有堆/协作取消、Native前台调用与ABI1边界继续适用。已安装副本不会随build自动更新，必要时重新运行安装脚本。
