# 项目概览与进度

更新：2026-10-11。Hua 0.1.0-dev / 规范0.1 / Native ABI1 / HUAB普通程序6、新错误能力7、File能力8、读取1–8。

Hua已是可执行的语言原型：C++前端可检查/运行源码与HUAB、加载本地/Native/WASM/可选Python Bridge；17标准模块、153标准函数、38内建。Hua链路已有词法/Parser/名称类型/降级/指令及C07完整HUAB6/7容器编码；四路径与样例已验，新完整自身预算未通过，尚未完成代际自举。
