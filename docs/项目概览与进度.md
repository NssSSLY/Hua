# 项目概览与进度

更新：2026-10-09。Hua 0.1.0-dev / 规范0.1 / Native ABI1 / HUAB普通程序写6、新错误能力写7、读取1–7。

Hua已是可执行的语言原型：能检查与运行源码、导入本地模块、生成并运行HUAB，使用Native/WASM扩展和可选Python Bridge。已有16标准模块、141标准函数、38公开全局内建；Hua词法器能扫描自身，完整编译器尚未自举。

开始写程序见 [开发与运行指南](开发与运行指南.md)，查接口见 [标准库与内建接口](标准库与内建接口.md)。标准库下一阶段先审阅 [设计路线](标准库设计与实现路线.md)；候选接口不计为当前能力。
