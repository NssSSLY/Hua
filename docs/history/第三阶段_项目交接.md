## 运算符与注释

`/` 真除法；`//` int 向下整除；`%` 与 floor division 一致；`**` 幂，保留 `//=`。
`#` 行注释，`#* ... *#` 可嵌套块注释；`##` / `#** ... **#` 文档标记预留，当前跳过正文。
首行 #! shebang 忽略；块层按各自标记闭合；所有注释换行保留；字符串标记不启动注释。
旧 // 注释和 /* */ 块注释不再支持。
补充 UTF-8/NEWLINE、闭合/空块与错误示例、运行示例及注释不进入 bytecode 的说明，见 词法与语法规则.md。

## 当前限制与后续

字节码为内存结构并引用语义声明；不支持 `.huab` 写入/读入、独立字节码文件或磁盘缓存。
当前只加载 Hua 源模块；没有 builtin 模块命名空间、Native/WASM、网络包管理或 HUA_PATH 搜索。
不要将直接 core 函数等同于已实现 import math/http/sqlite/ai。
仍未实现多返回/Result/Map/ref/ptr/FFI/GC/async/LLVM 等能力，保持明确拒绝。
后续可补这些语言能力，或单独设计可验证的磁盘字节码格式与包搜索合同；没有待用户确认的当前决定。
扩展时继续保持前端/语义/运行时/VM 分层，以及两种引擎的 stdout/错误对照。
