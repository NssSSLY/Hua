## 用户任务与当前范围

用户确认先完成输入/文本/字符串/JSON，再扩展网络/数据库；随后询问自举并要求“先补齐字节/二进制文件、动态列表和缓冲接口”。
本次完成这批数据接口，不自动编写 Hua 编译器、网络/数据库或推送 Git；没有等待用户决定。
新增 36 函数，总计 73，合同见 [Phase 7](../第七阶段_字节与动态容器.md)，Hua 规范 §34/66/73 同步。

- Bytes 不可变，任意字节、索引/切片/连接/文本数字转换、小端 u32/i64 与 CRC32。
- Buffer 共享可写句柄、可追加字节/文本/整数；bytes() 独立不可变快照，text() 验证 UTF-8，clone 独立数据。
- List<T> 是恰好一个非 void 参数的内建泛型；from_slice 深复制，append/extend/get/set/pop/clear/reserve/snapshot。没有直接索引、元素地址或迭代语法，遍历 snapshot。
- List 类型不变；snapshot 固定序列、不深复制嵌套共享容器；get/pop 嵌套共享值只读。修改需 var/mut，别名/Result/赋值/方法和运行时检查不提升能力。
- fs.read_bytes/write_bytes/append_bytes 沿用现有路径/普通文件/错误合同，不验证内容 UTF-8，不改变换行；父目录不自动建，写入非事务。
- Bytes/Buffer/二进制文件 128 MiB，List/数字转换 1,000,000 项，文本转换 16 MiB。列表/缓冲范围/资源 Err 在修改前检查。
- HUAB v4 只冻结新 intrinsic 合同，布局/opcode 不变；v3 仍可使用旧 37 个，新 36 个要求 v4。新值只在运行时创建，不保存运行状态，Native ABI 1 不扩展。

Phase 5/6 的值/输入/JSON规则有效，详见对应文档。`/` 真除法、`//` 向下整除、`%` 对应取余、`**` 幂、`//=` 不变。
注释为 #/嵌套 #*，文档标记 ##/#** 预留、首行 shebang 忽略；// 与 /* */ 不是注释。
