## 本次用户范围与冻结决定

用户要求建立程序输入与基础标准库，覆盖文件、字符串与 JSON，然后扩展网络/数据库；补充回答明确选择“先完成基础库，再扩展网络/数据库”。
当前阶段已实现并验收，没有等待决定；HTTP/SQLite 留到后续任务，不在本次自动启动。
37 个接口、UTF-8/资源/错误规则见 [第六阶段_程序输入与基础标准库](../第六阶段_程序输入与基础标准库.md)；Hua 命名规范 §34/66/72 同步。

- std.os/io/fs/strings/json 保留内建命名空间，不能被本地文件覆盖；导出函数签名参与语义检查，函数值/重复导入/别名可用。
- run/interpret 支持 `file [-- args...]`；os.args 返回分隔符之后的参数，保留 Unicode/空参数；RuntimeContext 显式传递 stdin/参数/启动工作目录。
- 文件路径基于启动目录，import 仍基于入口目录；普通 UTF-8 文本，Result 报告错误，remove 不递归，写入不提供事务或原子替换。
- strings 采用字节偏移，rune_count 数 Unicode 标量，slice 校验字符边界；trim/case 限 ASCII，split 返回只读 Slice。
- Json/json.Value 为不可变异构 JSON，禁止重定义 struct Json；null 与 nil 区分；重复键后值覆盖，输出按键排序、紧凑编码。
- JSON 数值限定 int64/有限 float64；文本 16 MiB、节点 1,000,000、深度 64；严格 UTF-8/数字/转义/语法，错误为 Result。
- HUAB v3 冻结注册表，字段/opcode 布局不变，v1/v2 拒绝标准 intrinsic，未知引用 E6002；ABI 1 不变。

Phase 5 规则继续有效，详见 [第五阶段_映射多返回与结果语义](../第五阶段_映射多返回与结果语义.md)；Optional<Result>、Map 直接 Result 值、通用 Tuple、完整流分析/函数返回写能力仍未开放。
注释沿用 `#`、嵌套 `#* ... *#`；`##`/`#** ... **#` 文档标记预留，首行 shebang 忽略。

## 关键实现位置

- include/hua/stdlib.hpp、src/stdlib.cpp：37 函数注册表、RuntimeContext、共享标准函数实现/UTF-8 检查。
- include/hua/json.hpp、src/json.cpp：不可变 JsonData、严格有界 parser/encoder、访问/转换；Value 末尾追加 Json 包装，Native 标量标签不变。
- module.cpp：生成标准模块签名接口、std 导出链接、Value→Json 类型别名、禁止 struct Json；链接后的 Program 没有标准函数体。
- sema.cpp/runtime.cpp：签名/只读能力、动态类型与多值参数检查；interpreter/vm 分别执行控制流，共用标准函数调用。
- main.cpp：`--` 参数、stdin、cwd 与 Windows UTF-8 控制台；archive.cpp：写 v3、读 v1/2/3 与 intrinsic 校验。
- tests/stdlib_tests.py：真实文件/stdin/Unicode 参数，源码 VM/解释器/删除源码 HUAB，独立 Python JSON 对照、跨模块 Json 和格式兼容。
- examples/standard_library.hua、examples/data/profile.json：参数→文件→JSON→stdin→字符串工作流；CMake 新增 stdlib_input 测试。

## 部署与当前边界

HUAB 保存代码、最小声明、来源文本和扩展接口；参数/stdin/cwd/外部数据在每次运行时传入。CRC 不是签名，嵌入来源用于诊断，不提供源码保密。
Windows 同目录需 hua.exe、wasmtime.dll、wasmtime-LICENSE.txt；WASM 嵌入 HUAB，Native DLL 另带，-o 不复制依赖。
SDK/编译工具包在 .tools，不提交；官方来源/哈希/实际 C ABI 见 [Phase 4](../第四阶段_字节码文件与扩展.md)。
