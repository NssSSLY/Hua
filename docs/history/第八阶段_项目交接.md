## 用户任务与本次完成

用户希望引入 Python 解释器，在前期利用 Python 包补充扩展。已提供默认 OFF 的可选 Native 插件；不用 Python 的 Hua 程序不依赖其 DLL/安装。
[Phase 8](../第八阶段_可选外部解释器桥接.md) 与规范 §74 冻结 13 个 wrapper 接口：init/version/add_path/import_module/getattr/from_value/call_kw/call/to_json/to_string/release/active_handles/shutdown。
返回 Result<...,string>；对象为正整数句柄，最多 4096 个/单调不复用。call 的实参是句柄数组和 string→handle Map；from_value 走 std.json.encode，to_json 返回 Json。
JSON 仅精确内建兼容值/int64/有限float/UTF-8/string-key，tuple→array；复杂实例保留句柄调用显式方法。协议16MiB/深度64/节点1M、参数各1024。
每进程一次解释器生命周期、初始化线程调用、同home重复init成功；无效home预检查可重试，shutdown/内部初始化失败后不重启。
isolated 配置：安装site可用，环境路径/用户site/CWD不自动加入，项目路径显式add_path。full CPython API/PyConfig，不是Limited/Stable ABI，只验收Windows x64/3.12.0。
异常含SystemExit转Err，Native缺失/加载/ABI仍沿原E7001/2/4；check/build要求插件文件存在但不启动Python。HUAB不嵌入Python/DLL/包/运行对象。
显式release/shutdown；插件驻留到进程退出，避免loader-lock析构内finalize，未shutdown不保证atexit。单线程Hua→Python调用有锁/GIL；无回调/多解释器/跨线程/抢占预算/沙箱。
没有Python→Hua转译、typed binding、二进制零复制、包管理；Hua标准库网络/数据库和自举仍未完成。未提交/推送Git。
