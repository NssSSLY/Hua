## 运算符与注释

`/` 真除法；`//` int 向下整除；`%` 对应取余；`**` 幂，保留 `//=`。
`#` 行注释、嵌套 `#* ... *#`；`##` / `#** ... **#` 文档标记预留；首行 #! 忽略。
`//` 与 `/* */` 不是注释，不恢复旧 Go 注释临时方案。

## 分层与部署

Parser/AST 保留源码位置，SemanticModel 保存类型/写能力，module 链接顶层多绑定名称和新 core。
Value/Runtime 提供 Map、位置值、Result 与共享类型/复制/只读/目标逻辑，Interpreter 和 VM 分别执行控制流。
VM 不回退 Interpreter；HUAB 读取只重建最小声明，由 BytecodeImage 持有 Source/声明到运行结束。
CALL 结果类型保留 Optional nil 默认数值上下文，解释器和 HUAB/VM 使用同样检查。
HUAB v2 沿用 v1 payload 布局并新增指令元数据检查；CRC 不是签名，源码文本用于诊断，文件不能隐藏源码。
Windows 同目录需 hua.exe、wasmtime.dll、wasmtime-LICENSE.txt。WASM 内嵌；Native 动态库另带，-o 不复制依赖。
SDK 与工具包在 .tools，不提交；官方来源/校验及 C ABI 合同仍见 Phase 4。没有全局工具安装或 PATH 更改。
