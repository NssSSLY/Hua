## 2026-10-05 后续冻结：独立注释符号家族

用户直接要求将新注释方案作为冻结的规范更新落地，取代此前“注释暂缓”的临时规则。
保留 `/` 普通除法、`//` 整除、`%` 取余、`**` 幂；`//` 在所有位置都不再作为注释。
采用 `#` 单行与可嵌套 `#* ... *#` 块注释；预留 `##` 与 `#** ... **#` 文档标记；首行支持 `#!` shebang。
Lexer 改为迭代 depth 计数与每层闭合标记，保留注释内换行，Parser 保留已有运算优先级。
旧 Hua 示例、测试与当前规范已迁移，原始 Nova 规范和历史里程碑保留用于追溯。
