## 1. 目标与不变边界

近期主线仍是：**语言基础 → 基础标准库 → 编译器自举 → 应用扩展与高级优化**。三步是产品验收顺序，开发可按真实依赖穿插；B不等待C全部完成，也不要求为了首次自举先实现所有应用库。

- 小核心、静态类型、显式转换、struct/interface/composition；不新增class继承。
- 数值、复制/别名、readonly/mut、Result/Optional/Diagnostic、资源关闭与Task清理规则保持；已确认ER/RS及E0不重选。
- 编译器主体算法由Hua实现，复用现有C++ VM/GC/OS原语；C++代做sema或编码不能算Hua编译器成果。
- 自举子集、编译器覆盖、发行语言基线分别报告。自举成功不要求同时把运行时改写为Hua。
- 默认构建tests/build；新实验tests/artifacts；诊断tests/tools。旧产物路径按[迁移表](../tests/目录迁移表.json)定位，归档CMake缓存不能继续构建。

### 4.2 结构性方案与本轮修订

首轮返回变换池/局部日志及第二轮来源投影/稀疏覆盖/组成版本均已做完整语义对照；后者物理重访实际减少，但总步骤与内存仍回退，默认源码保持。第二轮已验机制在[显式实验](../tests/experimental/c04-symbolic/README.md)，归因和失败只在[过程记录](../.codex-sync/knowledge/bootstrap-performance/runs/2026-10-20-c04-symbolic.md)。不再把增加包装/缓存本身当作下一交付。

**R1：共享不可变形状，摘要保存变换与例外。** 在单次编译会话内精确表示类型形状、字段路径、来源集合和只读/复制标志。完整ShapeId/PathId不是强制新框架；先对最重的参数/返回/写效果做内部切片，用已有Map/List表达也可。摘要保存“形式来源→实际来源”的可复用变换计划与稀疏例外，避免每个调用都给整张宽字段表重绑字符串来源。共享来源操作、已解析写效果和精确字段键覆盖已有候选。数字事实/直接覆盖查询、按需复制策略和精确形状比较已在[显式候选](../tests/experimental/c04-direct/README.md)实现，最终隔离合同通过；完整对照仍被宿主准备120秒阻塞，未放行。TypeId仅是形状内局部编号，来源仍是Map＋操作串，完整OriginId尚未实现。事实池/短句柄仍为未验收的表示候选，旧值/跨图/递归能力隔离与配额必须核对；本轮直接负载已把优先级转回真实调用写效果/重分析的变化证据，不把“先拆池”设为默认自举前置。不能绕过A07或引入无隔离全局池。仅给返回值加惰性包装但反复物化、增加所有热函数参数，已证明不足。

投影按需要得到事实；确需完整表时只在明确边界物化并复用。不能把前轮失败的惰性方案重新上线：它在每个消费者重新物化，整链步骤曾反增6.48%。共享元数据必须不可变，写入分离；未知、超8层、512路径截断/重置、record_copy、alias、readonly/mut、defer及多返回位置语义逐项保持。所有新缓存限定在编译会话内，有容量、失效和精确回退，不把缓存保留量失控换成速度。

**R2：按读到的事实版本失效，环境保存局部差量。** 保留现有dirty/dependents，进一步记录函数实际咨询的摘要/返回/写效果/全局与实参事实版本；被咨询部分没有改变时复用已验证结果。环境使用不可变基底＋局部写入/版本差量，join只处理真正变化的绑定/字段，不能简单取消clone而破坏隔离。输入绑定、全局、alias集合、只读标志或defer上下文变化都必须触发正确失效；未知情况回退原路径。

试验已分离returned/writes/required/control版本，记录来源路径、存在性和根能力；函数体按原实参下的返回精确相等及其他通道未变来复用事实/首错。这是已验证切片，仍不等于逐字段增量分析：写/要求等通道的细粒度、局部状态复用和BodyMemo保留配额待补。

先保持当前声明顺序和32粗轮/未收敛保守边界。确定性工作列表或SCC只在依赖/递归证据支持时进入，不强制先建完整CFG/SSA，也不承诺它能缩小互递归Parser的大SCC。最后的诊断按既有顺序选择，不能因调度顺序改变首错或漏掉重分析后的错误。

本轮默认完整负载显示，重访之外还有每次事实传递成本扩大。因此下一步先在analyze/statement的实际调用点记录被咨询摘要哪个通道改变、真正改变的字段与重访边；据此评估“函数体一次建立传递约束/计划，变化只驱动受影响节点”，避免每轮重扫整棵AST。此为待验证方案，未实施，不用现有整函数缓存或版本表冒称已完成。必须保留首错、A07及逻辑计量兼容；需要更改统计合同则单列核定，不伪造工作量。

**R3：再决定运行时剩余改造。** 若R1/R2后实际热点仍在Node/Result读取、Value复制、调用生命周期或GC，再选择UR-4或具体布局改造。若热点移到Parser/C05/C06/编码，则处理新热点。以完整同源工作负载的实际数据决定更深VM/后端，不能仅因“仍未自举”就再次推翻整个VM。

### 4.4 正确性、统计与预算必须分清

默认合同保持。第二轮试验已核对兼容计量：work重放原等价遍历的逻辑费用，passes/32轮及声明次序保持；可能越过1048576时执行原遍历定位首个失败。196例及两份真实完整报告包含统计字段均一致，没有静默忽略work/passes。物理body_visits和VM步骤另报：153次重访不是168次，真实步骤没有补偿或伪造。更换调度/统计含义仍须明确兼容或版本责任；本轮不因此变更默认报告。

类型/来源/能力、unknown、alias、写后事实、首错/位置、实际HUAB与执行结果必须精确对照。新增物理计数独立记录，实际VM步骤不能伪造、重置、隐藏或以取消检查取得下降。内核、真实小输入、完整自身分别给出证据；多个历史百分比不能相加/相乘预测当前完整收益。

### 4.5 固定限制与失败纪律

### 11.2 A05节点池内部试验边界

本表保留表示不变量；A05试验18种载荷与当前Parser扩展59种分开看，不把最初表示试验当成完整语法。缓存/摘要的会话版本也不能用稳定NodeId代替内容版本。

| 项目 | 试验规则及边界 |
|---|---|
| Pool/ID | create生成进程内递增池身份；NodeId和SourceId均含pool/index，get及span拒绝跨池、负值、越界、记录ID不一致。身份不跨运行持久化，不是内存地址 |
| 子项 | 先子后父；每条边的child.index小于parent.index。保留输入顺序，可共享同一子项；add/replace拒绝自环、前向边和跨池边，无占位/删除/索引复用 |
| 变体 | Integer/Float/Boolean/Name/Parameter/Unary/Binary/Assignment/Binding/Function/Parameters/Call/Block/If/While/Return/ExpressionStatement/Program共18种，enum严格检查载荷类型；验证器检查元数、名字/运算符及位置，不做语言类型检查或完整语法形状检查 |
| 子项角色 | Binary/Assignment为左、右；If为条件、then、可选else；While为条件、body；Call为callee、实参；Function试验建议Parameters、body。块/程序按源码顺序；类型、返回类型及let/var/const区分留待C02补齐 |
| 来源 | SourceInfo保存不可变Bytes、行起始表和名称；剥去一次开头UTF-8 BOM，CRLF/CR规范化LF。名称按字符串登记，重复同名同规范化文本复用ID，文本改变Err；路径规范化/版本化属C01/C02 |
| SourceSpan | SourceId、start/end半开UTF-8字节偏移、1起始行/字节列；EOF可零宽。拒绝负值/逆序/越界及伪造行列。列不是视觉列，字节偏移可落在多字节字符内；同当前C++ Source，不把它改成字符索引。父span不强制包含子项（支持多来源块），语法覆盖范围由C02校正；原文件偏移映射尚无 |
| 读取/修改 | get取得复制的节点记录；记录本身局部修改不写回池。子项只读视图的已知非法写入在A07-1后提前E3003；旧产物仍运行时E4007；clone节点后修改子项，replace明确写回。只读Pool参数传给mut API在静态E3003拒绝；不能声称所有深层能力均已静态推断 |
| 单次失败 | add/replace先核对身份、shape/span与全部边，再追加/设置；这些校验Err不改池。完整verify遍历记录检查上述不变量，不是Parser/sema替代品 |
| 遍历/预算 | preorder按出现次数、reachable按唯一节点；均用List栈迭代。limit是访问数量，负值/超限AST_WALK_LIMIT；不替代宿主百万步、容量或取消合同 |
| 重写 | rewrite_integer先收集唯一可达节点，再按ID升序处理；变化节点及祖先追加，返回新根，未变化子树复用。无变化不追加；共享子项仅改一次。预算预检Err不写池；中途宿主超限/分配失败没有整次事务回滚 |
| 失效/所有权 | replace保持身份但改变内容，旧根若共享该节点会观察变化；稳定ID不是版本号。C02/C03须选择分析缓存失效/修订策略。路径复制不改旧节点时旧根保持原内容 |
| 内部可信边界 | Pool是普通struct，字段并非opaque；约定只通过本模块API修改，禁止直接改identity/nodes/sources、clone整个Pool或把结构赋值当独立池。verify可检测测试中的损坏记录，不是防伪能力或安全沙箱。跨Task/持久化池/fork协议未设计 |
