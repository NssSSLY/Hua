## 现阶段目标 · 用 Hua 开发和分发 Hua

### 起点与依赖边界

- **已有 Windows 字节码自举。** Hua 编写的编译器从源码完成解析、分析、降级、校验和 HUAB 编码。最近一次同源验收中，已构建的原生编译器用 48.969 秒输出 HUAB，VM 运行种子用 308.588 秒生成 C2，再运行 C2 用 319.607 秒生成 C3。三份 HUAB 逐字节一致。此次原生编译器由宿主生成 C++ 后经 Clang 构建。Hua 生成下一代原生编译器归 N4。[自举入口](../selfhost/archive_main.hua) · [验收记录](../.codex-sync/knowledge/bootstrap-performance/runs/2026-11-18-n1-windows-acceptance.md)
- **标准库有 27 个内建模块、374 个内建标准函数和首个 SDK 源码模块。** 另有 38 个公开全局内建。宿主 reader 支持 HUAB 1–29，自举编码器按能力输出 6/7/17。源码模块的接口来自 Hua 声明，现有内建签名仍按实际依赖同步。[实际接口](标准库与内建接口.md) · [宿主加载器](../src/module.cpp) · [自举名称](../selfhost/catalog.hua) · [自举签名](../selfhost/signatures.hua)
- **实现归属。** 语言规则、诊断、生成器和可移植算法逐项移到 Hua。启动、VM/GC、OS 原语和链接保留必要宿主支持。每次替换记录还依赖哪些 C++ 前端源码、代码生成器、预编译运行库和外部工具链。第三方 C++ 库走薄 C ABI 包装，Python 包走可选解释器桥。[运行时与扩展](运行时与扩展设计.md)

### huaBin 目标目录与生成责任

仓库中的 `huaBin/` 由装配脚本生成。已交付 bin、src/compiler、lib/bootstrap、examples、manifest.json 与 licenses。源码标准模块、原生链接目录和外部包随对应能力交付。开发仓维护权威源码，装配时按清单复制；用户可在 SDK 中修改 Hua 源码并重建到独立目录，校验通过后再提升为新种子。

~~~text
huaBin/
  bin/                    hua.exe 和装载所需的 Windows DLL
  src/compiler/           来自 selfhost/ 的 .hua 源码闭包
  src/std/                已迁入的纯 Hua 标准模块，开发仓拟放 std/
  lib/bootstrap/          compiler.huab 种子
  lib/runtime/<target>/   原生链接所需运行库及接口，随原生能力交付
  toolchain/<target>/     Clang/lld 或清单声明的外部安装
  packages/               可选包的 .hua 包装、.huam 和平台库
  examples/               可构建和运行的示例
  manifest.json           文件来源、生产者、版本、目标、ABI、依赖及哈希
  licenses/               随包组件许可证
~~~

现有 SDK 编译入口从自身位置发现宿主和种子。SDK 根覆盖与标准模块清单校验随标准源码模块解析推进。项目模块、受保护的标准模块、显式外部包分别解析。生成的中间 C++ 和缓存放构建目录，需随包交付的少量 C++/Python 源码归对应包。[现有安装器](../scripts/install-local.ps1)

## 已确认合同与查阅入口

- **语言原则。** 小核心、静态类型、显式转换，使用 struct、method、interface 和组合。沿用 `#` 行注释及可嵌套的 `#* … *#`，`/` 真除、`//` 向下整除。数值、绑定、只读/可写及清理沿用已发布语义。[语言设计与类型规则](语言设计与类型规则.md)

### ER-DEC-01–08 · 错误基础

默认 `Result<T>` 使用 string 错误；`Result<void,E>` 允许无载荷成功。标准 Error 是名义只读值，程序以 domain 和 code 判断身份；原因链有界，上下文返回新值。旧 string 通过显式适配保留消息，传播时不自动打印。新增系统接口逐项盘点，现有签名保持兼容。[八项确认原文](../.codex-sync/knowledge/planning/2026-11-18-consolidation/originals/设计决策与未决事项.md#error-foundation-review) · [现行 Error 接口](标准库与内建接口.md#standard-error-contract)
