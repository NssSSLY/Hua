以 perf/vm-register-r1 的 51e0061 为源码基线。本机从空 huaBin 使用 x64 LLVM-MinGW Release 宿主及装配脚本重建。包内宿主、Wasmtime DLL、源码、种子、许可证和启动器按清单装配。清单覆盖 24 项，更新后逐项核对尺寸和 SHA-256。保留移植基线包供恢复。

## 宿主和 SDK 验收

- 将移植基线 SDK 整包复制到仓库外带空格目录，子进程 PATH 仅有 Windows System32，清除 HUA_HOME 和 HUA_PATH。样例输出为 2 2，移走源码后仍可运行。缺 DLL 和种子均给出路径诊断。两代自举在 158.028 和 192.564 秒完成。C2 与 C3 都通过独立 reader，迁走编译器源码后仍能编译和运行同一示例。产物 HUAB 17，4,297,861 字节，SHA-256 为 a7c35a53df9d1ca559d8915a02ca1f43c4a81ac1148ad36eb11dd4693af66257。
- 更新后的 SDK 使用当前 Release 重新装配，仍随包提供宿主生成的 C1。仓库外源码标准模块和种子 Task 用例通过。安装包内宿主 SHA-256 为 215dbbcb0eb67db3b28e5a5949faa6fbaaa038eee7ba1318c9d3906f9bfd2956，C1 SHA-256 为 791eb12535e1dea8f433a289476fbd2bffb75455415ceb038dc5e200f356db9e。

## N2.3 容器快照

- 支持只读 Slice、定长数组、List、Map 参数及对应结果，支持嵌套标量叶。原生参数在启动前进行带类型的递归复制，复制可见 Slice 区间并隔离字符串及容器存储。没有跨线程共享非原子引用计数。现有 TaskRuntime 负责结果深复制及一次性输出交付。
- Hua 前端采用相同的数据类型边界，await 的可变容器结果获得独立的写能力。定向用例覆盖父任务在启动后修改嵌套容器、字符串键值与定长数组，重复等待后独立修改结果，拒绝 mut 参数、只读内部写入和未开放的 Buffer 载荷。
- 原生／宿主 VM 差分 95 个通过，15 个子集外程序按预期拒绝，5 项定向 CTest 通过。默认无计步原生版两个同源容器用例的输出、诊断和退出码与 VM 相同。前后宿主对同一份同步自举编译器源码生成的 C++ 逐字节一致。未据此推断整体性能变化。
- 已修正 C03 回归对 HUAB 格式的旧断言。C02 仍为 7，C03 因 canonical 引用为 17，两者 ABI 均为 1。完整前端扩展语料单独复跑达到 300 秒上限，保留该结果。
