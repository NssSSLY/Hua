## 性能保留与诊断

既有9项core输出/步骤一致，两项真实编译约1.03x/1.01x，其余非字符串项0.99–1.04x。07_strings源码路径最终0.350582→0.371705秒，base/new=0.943x，仍约慢6%，不能宣称严格全项无退化。首轮5轮和定向9轮也有约5–6%差异，均保留。

一次定向诊断：旧新构建生成HUAB逐字节相同，直接执行同HUAB为1.03x；仅入口增加strings.repeat("x",32)分配，结果变为1.08x（均5轮、同输出/步骤）。支持前端后分配布局敏感的解释，未证明具体allocator原因，也未证明新增API使VM热路径变慢；保留源码基准差异，不靠调注册顺序/填充去迎合计时。本批功能验收通过，严格无退化性能验收仍保留该项。
