# Windows N3.5 原生发行（2026-11-24）

## 发布策略

小项目在同一次 Hua 类型检查和降级后生成一个 C++ 单元。阈值为两个源码模块且最多 256 个 Core 节点。标量运行时复用诊断与源码位置表示，覆盖整数、布尔、字符串、普通调用、控制流和输出。容器、结构体、Result 及其他能力沿用完整原生运行时。大型程序使用 N3.4 的逐模块对象缓存。

SDK 装配生成可搬移 PCH，并保存实际依赖及内容散列。首次使用核对散列，随后以 NTFS 快照复用已验证的依赖集合。构建开始和发布前分别调用一次分组快照，编译、链接和生成器身份独立计算。PCH 缺失、损坏或头文件变化时回退。链接移除 C++ 调试符号，回收未引用节，保留 Hua 自身运行诊断。

## 冷构建和独立 EXE 尺寸

Windows x64 同机交错七轮。每轮使用不同的空应用缓存，从启动 hua build --release 到进程退出计时。N3.4 的基线来自本机旧 huaBin，N3.5 使用正式装配包。数字按毫秒汇总。

| 负载 | N3.4 中位 ms | N3.5 中位 ms | N3.5 最慢 ms | N3.4 EXE 字节 | N3.5 EXE 字节 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Hello | 2726.168 | 783.809 | 848.352 | 3,322,368 | 477,184 |
| 标量两模块 | 6364.985 | 797.618 | 848.272 | 3,329,536 | 479,744 |
| 结构体与容器两模块 | 7113.853 | 1959.794 | 2013.309 | 3,360,768 | 1,927,168 |
| 源码标准模块 | 6476.498 | 1448.419 | 1564.391 | 3,337,216 | 1,912,832 |

Hello 和标量两模块达到首次构建低于 2 秒及 EXE 小于 1 MiB 的目标。结构体与容器示例的中位数低于 2 秒，最慢一轮略超，EXE 约 1.84 MiB。链接映射显示其完整运行时仍包含通用标准库、值表示、C++ 本地化、异常名称解析、任务与文件实现。曾试验让输出直接使用既有格式化，EXE 仅减少约 16 KiB，因此正式发行保留原完整运行时。映射位于 size/base.map 和 size/direct-print.map。

## 原始 PE 与 ZIP

ZIP 大小 125,866,332 字节，SHA-256 为 72c8eaf0c9b976016206786d6d48b983a5ebd8e97f15d007141d25ba28432415。解压到中文空格路径后，核对 5,128 个清单文件。四类样例在原 SDK 和解压副本、不同项目目录与输出名、空缓存和关闭缓存下分别输出同一 SHA-256，应用 EXE 单独运行通过。容器和源码标准模块证明 PCH 在 ZIP 搬移后仍能使用。相同大小且恢复普通修改时间的头文件编辑、缺失 PCH、损坏 PCH 均回退，输出 EXE 保持同一哈希。修改并恢复标量模块源码后，EXE 哈希恢复。标量运行时对整数溢出、除零、递归深度和有符号计算与 N3.4 输出及退出码一致。

早期实测中，Clang 在中文路径搬移后会再次包含已经进入 PCH 的原生运行时头，导致重复定义。添加显式包含保护并重制 PCH 后，原始 PE 对照通过。首次正式验收还修正了 Windows 环境变量从普通 Python 字典读取时的大小写差异，原始程序结果保存在验收目录。

验收平台为本机 Windows x64。独立实体机的安装和复现另行登记。原始回执见 tests/artifacts/n3-5/acceptance。

## 完整生成器及正式安装

完整生成器冷构建 240.208 秒，编译 13 个对象。热恢复 0.183 秒，跳过生成、编译和链接，EXE 哈希一致。改变真实词法器函数体后只重编 lexer.hua，端到端 52.089 秒。改变 Token 字段后只重编 Lexer 和 Parser，并读回 E2001@77:10，端到端 75.828 秒。全组在原 600 秒单次上限内完成。既有发布缓存套件产生 28 份成功构建回执，同时完成失败保护、导入遮蔽、初始化顺序、并发和损坏对象等断言。

正式 huaBin 已替换并通过 PATH 中的 hua run 及 hua build --release。最终目录两模块结构体和容器样例冷构建 2.096 秒，使用 PCH，热构建 0.075 秒，EXE 输出 2 2。旧 SDK 备份为 tests/artifacts/n3-5/previous-huaBin。
