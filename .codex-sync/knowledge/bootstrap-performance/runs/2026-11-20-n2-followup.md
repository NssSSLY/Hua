# Windows N2 按需快照、完成投递和 Task 载荷

2026-11-20。基于 5d206c4 加上同日已验收的 Task 收拢优化。Windows x64，Clang Release。源码、可执行文件、原始样本和自举日志在 tests/artifacts/n2-followup-20261120/。本次未修改公开语法和 HUAB 布局。

## 改动

- 已知入口沿静态函数引用及嵌套任务分析模块槽位，只快照可达模块变量。动态调用、方法与标准库回调按整模块处理。缺省槽保留未初始化状态，启动前取得快照。递归依靠已访问声明集合结束。
- 让出将已停稳的帧重新入队。阻塞池和 IOCP 在调度锁内按请求匹配登记。已归属的原生纤程通知自己的 worker。先完成再登记通过完成标记直接入队。祖先取消、一般等待及定时器仍使用谓词检查。IOCP 在请求取消后仍等系统完成通知，再退休缓冲和文件控制块。
- 原生及 Hua 自举前端 Task 支持 Bytes、Optional 和 Result 的受控载荷。原生复制 Result 的活动分支和错误轨迹，Bytes 使用只读共享内容。其余类型仍由既有限制保护。原生同时修正同底层类型的 ok 值转换为带 Optional 的 Result。

## 原生 A/B

同一源码、同一工具链、禁用计步。先热身，再反转顺序交替运行 12 对。测量包含程序启动、执行和进程退出。完整自举 C2 同期运行，以下数字保留此机器负载条件。配对测试逐次检查标准输出。一到超时即停止。

| 工作量 | worker | 基线中位数 / ms | 候选中位数 / ms | 降幅 |
|---|---:|---:|---:|---:|
| 32 个短 Task，模块有一个无关 10 万项 List | 2 | 25.83 | 15.31 | 40.7% |
| 8 个 Task 共 16 万次 yield | 1 | 138.33 | 67.58 | 51.1% |
| 同上 | 4 | 127.70 | 66.84 | 47.7% |
| 8 个 Task 共 16 MiB 缓存读，每请求 4 KiB | 1 | 54.45 | 52.86 | 2.9% |
| 同上 | 4 | 31.26 | 29.60 | 5.3% |

生成的快照函数确认 32 次启动只复制所读模块槽，省去对无关 List 的 320 万元素处理。首轮独立模块 A/B 为 23.82 → 14.19 ms。首轮 yield A/B 为 137.67 → 74.05 ms（1 worker）、127.97 → 67.32 ms（4 worker）。小块 I/O 的中位数移动幅度有限，保留逐样本数据，不作为主要提速结论。

复现命令为 python tests/tools/n2_task_followup_bench.py <baseline-hua.exe> <candidate-hua.exe> <output-directory>。两份宿主旁均需对应静态库和依赖。配对报告在 paired/report.json。基线宿主 SHA-256 为 00c7687d326378e7f6876d9525f9b525bae2a990c68eb5889fa7fceb8e12bb4f，候选为 d5cac92984fa6fcb195b5e0a2c9d9a771d6060e0aa21288b782d42c8cf6d6bf0。

## 语义和平台复验

- native_backend、file_stdlib、task_resume_single、task_resume_migration、task_resume_public 共 5 项通过。106 个原生/VM 程序一致，12 个不支持用例在原生生成前拒绝。Task 恢复专项分别为单 worker 437 个断言、双 worker 443 个断言。
- Windows 矩阵覆盖 AST、源码 VM、宿主 HUAB、Hua 自举 HUAB 和原生文件程序。阻塞池及 IOCP 的持久化文件内容均相同。该脚本允许合法的取消竞争终态。它验证真实文件路径和协议，内核取消的精确交错仍需专项。
- 同期矩阵的 1／2／4 worker 长计算中位数为 137.48／88.82／59.24 ms。128 MiB 缓存读的阻塞池／IOCP 中位数分别为 47.64／37.85 ms。每格为 7 次，本轮不据此推断尾延迟。见 windows-matrix/report.json。
- 新建 C1 和现有宿主通过 8 个自举 Task 正例和 9 个反例。嵌套捕获反例在宿主 VM 得到 6，Hua 编译器 types 阶段返回 E8201@3:5，复现保存在 nested-closure.json。仍需把闭包声明、自由变量能力及 HUAB 闭包指令贯通，再补结构体和枚举载荷。N2 整体仍未关闭。
