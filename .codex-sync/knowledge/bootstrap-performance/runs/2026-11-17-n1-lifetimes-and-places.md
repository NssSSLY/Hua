# N1 闭包、函数值和赋值位置（2026-11-17）

用户确认实施性能优先方案。基于 perf/vm-register-r1 的 a4eec89 与前两批未提交的本地后端改动。生产 VM 和 HUAB 格式未改动。

- 赋值按位置解析、右侧求值、转换和快照、Map 新键容量预检、按目标顺序写入执行。字段保活原记录，数组和 Slice 保活原存储，Map 保留原容器与键。普通局部字段经证明可在右侧结束后直接定位。
- 复杂捕获保留记录、固定数组、容器、部分接口和枚举的快照与共享规则。捕获环境按使用分类放在栈或持久存储。可形成循环的本地对象复用 ManagedHeap，生成强边枚举和清除操作。零长度递归 Slice 的新建 backing 可共享，只读投影仍属于各个值。
- 单一声明保留直接调用。同签名分支函数用带类型的入口，异签名标量调用使用现有 Value 类型检查。变量重赋保留 VM 从首个函数值推断的声明身份。同一声明的闭包可进入 Slice。支持具体结构的绑定方法及 defer 捕获的函数值。

已知开放项：完全未知或未注解的高阶签名，以及异签名的容器、mut 参数、复杂返回等通用适配；混合声明函数容器；接口和索引接收者的绑定方法；File 在隐式捕获环境内的可观察保活及 clone 资源检查。这些尚未宣布通过。继续基于实际 VM 可接受输入补齐。N2 异步和跨平台验收分开。
