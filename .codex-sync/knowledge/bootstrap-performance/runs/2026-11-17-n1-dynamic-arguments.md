# N1 高阶参数、动态复合值与 File 捕获（2026-11-17）

基线为 perf/vm-register-r1 的 a4eec89 及此前 N1 工作区改动。本批对照生产 VM，工程实现位于原生后端。

- 未注解实参通过保持具体类型的动态值传递。实际调用类型、数量和 mut 能力在实参全部求值后核验。标量沿用原有转换检查，结构、容器和复合返回保留原生表示与对象所有权。多值拆分遵循先完成检查再写入，动态返回转换仍在 defer 清理后。
- 支持结构和接口的动态 mut 借用、可写固定数组到 Slice 的原存储借用。混合声明 Slice 按 VM 的元素类型规则检查声明身份，诊断指向失败元素的求值位置。
- 结构索引与接口绑定方法保留接收者身份。可通过高阶参数传递接口绑定的具体方法，直接绑定为接口原型类型仍按 VM 报 E4003。
- File 及可能含有 File 的未使用局部绑定进入闭包快照。clone 按当前拥有者和 Slice 可见范围扫描，支持创建后才从可写别名写进共享容器的 File，直接和间接闭包都能拒绝不安全复制。常规直接调用和同签名的类型化实参保持此前路径。

验收覆盖函数实参求值顺序、布尔谓词、类型不匹配、动态多返回、值复制、借用到原对象、绑定接收者原存储、越过定义作用域读 File、隐藏 File 和后加入 File。未注解数据的任意字段/索引操作和任意动态接口互转没有纳入本轮验收。Task 与平台相关放行仍分开。

## 本机证据

- Windows 原生差分 78 个程序的 stdout、stderr 和退出码均一致，1 个 Task 用例预期拒绝。定向 CTest scope_reuse、struct_cow、language_structure、gc_allocation_contract、file_stdlib 和 native_backend 均通过，最后的谓词与返回校验改动专门复跑了 native_backend。
- tests/artifacts/n1-dynamic/matrix.json 中 132 项标准库、7 项核心基准和 23 项示例与 VM 一致，4 个示例仍受原有异步、扩展二进制和 unsafe 前端限制。未复跑完整自举。
- tests/artifacts/n1-dynamic/native-ab.json 复用同一输入，三对进程交替，每进程预热 8 次、取 7 个 4 次批量样本。无计步本地版前后中位数（毫秒）为 间接调用 8.623→8.614；闭包创建 58.514→57.969；多重赋值 3.364→3.399。这些测试的差异在约 1.1% 内。
