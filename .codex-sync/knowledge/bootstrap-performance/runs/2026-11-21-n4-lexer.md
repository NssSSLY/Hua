# Windows N4.2B／N4.2C 原生词法器

2026-11-20 冻结源码并启动 C3，2026-11-21 复用已完成的生成器补完中断的差分。使用 Windows Release 宿主、N2 验收的 C3 种子和固定 Clang/lld。

- C05 原生后端覆盖词法器所需的 Bytes、Slice、List、Map、索引读写、复合赋值、范围和容器循环。复用运行库的带类型容器和可写位置，保留子视图、List 快照及 Map 循环快照的语义。
- Result 传播从当前 Hua 函数提前返回，并沿用错误来源链。支持 Optional 收窄，接入词法器实际使用的 list、bytes、strings 调用。测试入口用 os.args、fs.read_text 和 int 读取参数。
- strings.slice 切片时从共享字符串取片段，并复用 UTF-8 校验。198,000 字节合成输入上，优化前与优化后的词法器在四轮交错运行中产出同一输出哈希。进程总用时的中位数从 0.4075 秒降至 0.0765 秒，样本含启动和输出。
- C3 在 271.942 秒内重建生成器，低于 600 秒上限。HUAB 格式 17、4,262,446 字节、63,502 条指令。SHA-256 为 58d71a1f0e0054d583417b0fec1deaab8d62f30552b6b85555f928727233dc5a。
- 10 组真实或定向词法输入通过 AST、源码 VM、C3 编码的 HUAB 和原生 EXE 四路径。对照 lexer 与 lowering 实源、BOM、CRLF、嵌套注释、转义、E1001 至 E1005 及两项 E8202 预算错误。比对 token 文本、类型、偏移、行列，错误理由、主诊断位置和退出码。移走词法器源码后复跑 HUAB、EXE，结果仍一致。
- 7 组新语言差分、7 组 N4.2A 回归和 4 组标量回归通过。2 组拒绝样例保留已有 C++ 与 EXE。
- 原生词法器生成 C++ 用时 2.765 秒，固定工具链编译和链接用时 18.375 秒。两项均为单次测量。

复验入口为 tests/tools/n4_lexer_acceptance.py。原始产物位于 tests/artifacts/n4-2bc-20261120，包含 final-inputs.json、final-bootstrap.json、final-recovered/report.json 与 slice-scaling.json。
