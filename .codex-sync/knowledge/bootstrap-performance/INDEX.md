- 同输入前后与“当前完整自身”分别保存；冻结源码闭包、C0/运行时SHA、构建选项和机器状态。普通墙钟/CPU、诊断时间、内核操作数、累计分配、live申请及RSS分别解释；不同轮次改善不相加/相乘，嵌套计时不直接相加。
