# 测试与辅助文件

测试和非主干实验统一收纳在本目录。编译器源码、自举源码和正式使用示例分别留在根目录的src/include、selfhost、examples，不依赖历史构建目录。

| 位置 | 内容 | 是否纳入Git |
|---|---|---|
| 本目录的*.cpp、*.hpp、*.py、*.cjs | 单元/集成/契约测试、监督与诊断驱动 | 是 |
| spec/、runtime/、data/ | 语法、运行语义及合同夹具 | 是 |
| reference/、support/ | 独立参照实现与原生计量辅助 | 是 |
| tools/ | 性能审计、探针编排与CPU采样源码 | 是 |
| build/、build-*/ | 当前及可选配置的CMake构建、测试输出、VSIX | 否 |
| experimental/ | 未进入默认链路的候选覆盖源码与独立合同 | 是；不得误当正式模块 |
| artifacts/ | 原始日志、对照产物、冻结快照及旧构建 | 否 |
| 目录迁移表.json | 2026-10-20原路径到新路径对照 | 是 |

默认构建、安装与运行命令以 [开发与运行指南](../docs/开发与运行指南.md#project-layout) 为准。在仓库根目录运行：

```powershell
cmake -S . -B tests/build -DCMAKE_BUILD_TYPE=Release
cmake --build tests/build --config Release
ctest --test-dir tests/build -C Release -R "^(frontend|cli_version|cli_hello_run|cli_hello_check|cli_hello_ast)$" --output-on-failure
python tests/bootstrap_readmission_tests.py
python tests/bootstrap_scale_audit_tests.py
python tests/tools/audit_bootstrap_phases.py --help
```

Windows本机CPU剖析：`tests/tools/native_profile/`（最忙线程采样器源码与 profile/callees/system 三个汇总脚本）。需要带 `-g` 的构建（如 `tests/build-prof`，`CMAKE_CXX_FLAGS=-g -fno-omit-frame-pointer`），采样器按源码首行命令编译到 `tests/build-prof/sampler.exe`，然后 `python tests/tools/native_profile/profile.py 输出.json 1 60000 tests/build-prof/hua.exe run ...`。

CMake配置、探针及某些测试仍需本机工具链/SDK。测试按改动范围选取；长自举与三代验收不作为整理目录的默认动作。触发超时应停下定位，不能重试掩盖问题。诊断脚本之间的同级导入已迁移；正式前端开发入口仍是tools/hua_frontend.py。

旧根目录的7个build目录和21个诊断文件已经迁移，具体见 [迁移表](目录迁移表.json)。旧构建内的CMakeCache/Ninja含原绝对路径，保留为证据，不能继续构建。日志与历史报告不改写，按表查找；其中旧冻结身份要求不能绕过。两个符号链接夹具改为同目录相对目标，目标文件内容保持。迁移逐文件校验、改前文件和本轮验证结果保存在本机artifacts/layout-20261020，不代表Git远程已保存这些产物。
